A premium, high-performance portfolio website built to showcase scalable full-stack applications, AI integrations, and agentic workflows. Engineered with **Next.js**, **Tailwind CSS**, and **Framer Motion**, delivering a modern, neon-accented dark mode experience with smooth micro-animations.

## 🚀 Live Website
**[https://portfolio-website-sable-three-87.vercel.app/](https://portfolio-website-sable-three-87.vercel.app/)**

## ✨ Features
- **Modern Tech Stack**: Built entirely with Next.js 14 App Router and JavaScript.
- **Dynamic Animations**: Smooth scroll transitions, hover effects, and a custom interactive command palette (Press `/` to open) using Framer Motion.
- **Responsive Architecture**: Fully responsive grid/flexbox layouts ensuring seamless UI across all devices.
- **Aesthetics First**: Vibrant neon glows, glassmorphism cards, and a minimalist custom typography scale.

## 🛠 Tech Stack
- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel

## 💻 Running Locally

### Prerequisites
Make sure you have Node.js and `npm` installed.

### Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/prince-rai88/Portfolio-Website.git
   cd Portfolio-Website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.
